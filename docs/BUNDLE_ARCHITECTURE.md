# Bundle Architecture

Defined in `src/config/commercial/bundles.ts` with prices in the commercial catalog.

| Bundle | Billing | From excl. VAT | Quote only |
|---|---|---|---|
| Website Launch System | one-time + optional care | €1,695 | No |
| Business Growth System | one-time + care | €3,495 | No |
| Webshop Launch System | one-time | €3,995 | No |
| Automation System | proposal | — | Yes |
| Digital Partner | proposal | — | Yes |

External provider costs may be separate. No automatic bundle discount until discount approval exists.

Shop and marketing pages render bundles via config + `formatDualPrice`.
